    How this works
    • Built from the statement files listed at the top. Run the script again after adding or replacing files to refresh it.
    • Categories come from the payee’s name and the note on each UPI payment. Add your own rules in my_categories.csv.
    • Money moved between your own accounts is never counted, so nothing is counted twice.
    • Payments to family are shown separately and only counted when you tick the box at the top.
    • Cash withdrawals count as spending, since what the cash bought isn’t known.
